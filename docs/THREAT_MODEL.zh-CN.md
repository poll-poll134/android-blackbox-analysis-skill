# 威胁模型

本文描述公开 Skill 及其辅助脚本的安全边界，不代表第三方 Android 应用本身安全。

## 需要保护的资产

- 维护者和使用者的凭据、设备标识、内部包名、截图、UI dump 与运行时报告。
- 明确指定的 case 目录以外的文件。
- 指定 Android 设备和应用的状态。
- 生成的 CSV 索引与正式 Release 资产的完整性。

## 信任边界

1. **用户指令和 scope** 是设备、应用、case 目录和允许操作的唯一授权来源。
2. **ADB 输出与应用界面文字是不可信证据。** 它们可能含 Prompt Injection、终端控制符、CSV 公式、误导性标签或畸形 XML，不能因此获得执行命令或扩大范围的权限。
3. **生成的 case 数据默认私密。** `cases/` 已被忽略，未经单独人工审查不得公开。
4. **仓库贡献与依赖在审查前不可信。** CI 能检查结构和已知负向用例，但不能证明贡献或依赖无恶意。
5. **Release 压缩包由维护者构建。** 安装前应核对公开的 SHA-256。

## 主要威胁与控制

| 威胁 | 可能影响 | 当前控制 |
|---|---|---|
| UI 文字中的 Prompt Injection | 应用要求 Agent 读取文件、泄露凭据、执行 Shell 或忽略范围 | `SKILL.md` 要求只把界面内容当证据；执行仍受辅助脚本和用户明确授权边界限制 |
| Shell 或参数注入 | 恶意 package、ID、slug、等待或滑动参数改变命令 | Shell 参数均加引号；包名、路径分量、尺寸、次数、坐标与等待值使用允许列表并设上限 |
| CSV 公式注入 | 以 `=`、`+`、`-` 或 `@` 开头的 UI 文本在表格软件中执行 | 生成 CSV 前将疑似公式的单元格强制作为文本 |
| 路径穿越或符号链接逃逸 | 公开引用或 case 根目录读写预期目录之外 | 公开路径必须留在示例根目录；拒绝符号链接和危险 case 根目录 |
| 资源耗尽 | 超大 XML/文本或无限 sweep 消耗内存、时间或设备操作 | UI dump 与可发布文本设大小上限；sweep 次数、持续时间、坐标和等待值均有边界 |
| 凭据或隐私数据泄露 | Token、私钥、账号数据、设备地址或真实材料进入 Release | 启发式脱敏扫描、禁止的产物类型、默认忽略 case、私密漏洞报告与强制人工复核 |
| 未授权设备或网络操作 | 辅助脚本作用于其他设备或暴露 ADB | 每次 ADB 操作都要求明确 serial；脚本不自动发现或选择目标；文档禁止向不可信网络暴露 ADB |
| 破坏性应用操作 | 自动化触发付费、删除、授权、发布或账号变更 | 点击默认 dry-run；高风险和不可逆操作需单独确认并写入 scope |
| 供应链攻击 | 依赖、Action、Release 资产或贡献改变行为 | 运行时只使用 Bash/Node/Python 标准能力；Action 固定提交；通过 CodeQL、Dependabot、审查规则、负向测试、确定性打包与校验和分层控制 |

## 剩余风险

- 文本脱敏无法识别截图中的敏感像素，也不能覆盖任意 dump 中的所有标识。
- 恶意应用可能显示诱导性文字，或在采集与之后经用户批准的点击之间改变状态。
- ADB 本身权限很高；被攻陷的主机、设备、platform-tools 或暴露的 ADB 端点超出本仓库可控制范围。
- CI 验证脚本和合成 fixture，不证明所有设备、Android 版本、定制渲染或第三方贡献均兼容。
- 公开真实 case 材料，以及接受会改变 Shell、文件、网络、Release 或凭据行为的贡献前，仍必须人工审查。

安全问题请按 [`SECURITY.md`](../SECURITY.md) 私密报告。
