# Changelog

## 0.1.1 - 2026-08-12

- Added an explicit threat model for prompt injection, shell and path injection, CSV formulas, sensitive evidence, ADB scope, and supply-chain risk.
- Added negative security tests for formula-like UI text, invalid shell inputs, symlink escapes, and oversized UI XML.
- Added bounded inputs, symlink and file-size checks, and broader credential/artifact scanning.
- Added deterministic installable ZIP packaging with a SHA-256 checksum.
- Added CodeQL/Dependabot configuration, CODEOWNERS, and sanitized bug and compatibility intake forms.

## 0.1.0 - 2026-08-11

- First public release with bilingual documentation, governance files, CI validation, and a complete sanitized synthetic example.
