# 示例分析范围

- 示例性质：完全合成的公开演示，不对应真实应用、设备或用户。
- 应用：`Sample Clone Manager`。
- 包名：`com.example.clone`。
- 版本：`1.0.0-demo`。
- 示例设备：`SANITIZED-DEVICE`，Android 10 / API 29，720 × 1280，竖屏。
- 允许操作：浏览免费页面、创建一个合成内部分身、打开卡片菜单、查看权限诊断。
- 禁止操作：支付、真实登录、删除账号、发送消息、安装外部软件、修改真实系统授权。
- 不可用前置条件：相机；付费会员；真实账号。
- 证据冻结点：`DEMO-0005`。
- 发布处理：真实截图、UI XML 和运行时 dump 不进入示例；使用合成页面摘要展示索引和报告链路。
