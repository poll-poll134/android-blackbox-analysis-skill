# Example Analysis Scope

- Example type: fully synthetic public demonstration; it does not represent a real app, device, or user.
- App: `Sample Clone Manager`.
- Package: `com.example.clone`.
- Version: `1.0.0-demo`.
- Example device: `SANITIZED-DEVICE`, Android 10 / API 29, 720 × 1280, portrait.
- Allowed actions: browse free screens, create one synthetic internal instance, open its card menu, and inspect permission diagnostics.
- Prohibited actions: payment, real login, account deletion, external messaging, external software installation, or changing real system permissions.
- Unavailable prerequisites: camera, paid membership, and a real account.
- Evidence freeze point: `DEMO-0005`.
- Publication treatment: real screenshots, UI XML, and runtime dumps are excluded; synthetic screen summaries demonstrate the index-to-report chain.
